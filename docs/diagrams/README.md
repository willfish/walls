# Diagrams

Source files for README architecture figures. Edit the `.mmd` file, then preview on GitHub or with [Mermaid CLI](https://github.com/mermaid-js/mermaid-cli):

```bash
mmdc -i docs/diagrams/architecture.mmd -o docs/diagrams/architecture.svg
```

The README inlines the same Mermaid for GitHub rendering. The TUI layout stays as ASCII in the README (it documents a terminal UI).
